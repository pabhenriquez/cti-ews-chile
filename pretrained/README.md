# Pretrained classifier

Files used by `make_fig_class_1.py` / `make_fig_class_2.py`:

- `best_model_1_1_len1500.keras`
- `best_model_1_2_len1500.keras`

These are publicly released 1,500-point multiclass classifier files (fold /
hopf / transcritical / no-transition); their source and training procedure
are referenced in the paper's Methods. They are applied without retraining.
